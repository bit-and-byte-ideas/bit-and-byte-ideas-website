# Bit and Byte Ideas Website

This repository contains the public website for Bit and Byte Ideas, a software studio focused on static website development, web application development, and maintenance plus hosting support for small and medium businesses.

The site is a single Angular application that presents the studio brand, service offerings, consultation booking, and direct contact path. The current product surface is intentionally compact: it is a marketing and lead-generation page rather than a multi-route application.

## What the Site Does

- Introduces Bit and Byte Ideas as a software studio.
- Explains three service lines: static websites, web applications, and maintenance plus hosting.
- Provides calls to action for exploring services, booking a consultation, and emailing the business.
- Embeds Calendly for a free 30-minute consultation.
- Centralizes business contact details through an Angular service.

## Repository Purpose

Use this repository to maintain the source code, assets, tests, and contributor documentation for the Bit and Byte Ideas website. Contributors should keep the website fast, accessible, clear for prospective clients, and aligned with the existing brand direction.

## Current Scope

The application does not currently include authentication, a backend API, persisted user data, or Angular route-driven pages. If those capabilities are added, update this documentation in the same pull request as the code change.
