# Bit and Byte Ideas Website

Angular website for Bit and Byte Ideas, a software studio offering static websites, custom web applications, and maintenance plus hosting support.

## Requirements

- Node.js compatible with Angular 21
- npm 11.x

## Setup

```bash
npm install
```

## Local Development

```bash
npm start
```

The development server runs at `http://localhost:4200/` and reloads when source files change.

## Build

```bash
npm run build
```

Production build artifacts are written to `dist/`.

## Tests

```bash
npm test
```

Run a focused Angular test file with:

```bash
ng test --include="**/example.spec.ts"
```
